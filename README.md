# Groupme

14 人、两次作业，队友不重样。一个白底、简约、无需登录的分组网页。

**在线使用：[mappedinfo.github.io/groupme](https://mappedinfo.github.io/groupme/)**

## 使用

1. 选择两次作业的组数：4 → 4、4 → 5 或 5 → 5。
2. 可填写 14 位同学的姓名，每行一位，也可以直接使用编号。
3. 交叉图每行是作业一的一组，每列是作业二的一组。点击任意同学查看两次的队友。
4. 点击「重新打散」交换同学的位置，再复制分组名单。

每次打散得到的两轮分组都保持零重复队友；这不保证与先前打散的历史结果也没有重复。重名同学在名单中附带编号。姓名与当前分组只保存在当前浏览器的本地存储中；网站没有后端、分析脚本或第三方字体请求。

## 分组依据

| 方案 | 作业一人数 | 作业二人数 | 重复搭档 | 不同搭档 |
| --- | --- | --- | --- | --- |
| 4 → 4 | 4、4、3、3 | 4、4、3、3 | 0 对 | 36 对 |
| 4 → 5 | 4、4、3、3 | 3、3、3、3、2 | 0 对 | 31 对 |
| 5 → 5 | 3、3、3、3、2 | 3、3、3、3、2 | 0 对 | 26 对 |

每个交叉格最多放一个人，意味着任意一对同学最多在一次作业中同组。指标由共享计算模块生成，随机打散只改变学生与位置的映射。4 → 4 是这三种人数较均衡方案中不同搭档最多的方案；不声称它对所有可能组型都最优。

## 本地运行

需要 Node.js 20 或更高版本，无需安装依赖。

```sh
npm start
npm test
```

默认预览地址为 `http://127.0.0.1:4173`，可通过 `PORT` 环境变量调整。请通过本地服务访问，避免直接打开文件时的模块加载限制。

## 项目结构

- `index.html`：页面结构。
- `src/style.css`：白底样式与手机布局。
- `src/app.js`：页面交互、本地保存与复制。
- `src/grouping.js`：分组模板、洗牌、统计和姓名校验。
- `tests/grouping.test.js`：分组约束与输入验证测试。
- `HANDOFF.md`：唯一当前状态入口。

GitHub Pages 从 `main` 分支根目录发布。所有网页资源采用相对路径，无构建步骤，`.nojekyll` 关闭 Jekyll 处理。
